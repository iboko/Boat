# Boat v0.19 — влияние шума датчиков на оценку параметров корпуса

## Постановка

Исследуется ранее реализованный оцениватель v0.18 на той же
**неидентифицированной расчетной трехстепенной модели корпуса**.
Он восстанавливает массу, линейное продольное сопротивление, момент
инерции и сопротивление рысканию по измеренным скоростям относительно
воды и известным физическим силе и моменту управления. Это не испытание
и не калибровка настоящего BlueBoat.

Базовая программа движения длится 36 с при шаге 0,02 с. Истинные
коэффициенты: масса 78 кг, продольное сопротивление 27 Н·с/м,
момент инерции 34 кг·м², сопротивление рысканию 23 Н·м·с/рад.
Для каждого уровня шума выполняется **60 независимых реализаций**.

| Профиль | СКО скорости относительно воды, м/с | СКО угловой скорости, рад/с | СКО курса, рад |
|---|---:|---:|---:|
| `ideal` | 0 | 0 | 0 |
| `low` | 0,001 | 0,0005 | 0,001 |
| `moderate` | 0,005 | 0,002 | 0,005 |

Каждое измеренное состояние содержит один случайный вектор шума;
в соседних разностях скорости общее измерение **не генерируется заново**.
Использован генератор Mersenne Twister с фиксированным начальным числом
и нормальные случайные добавки. Значения шума **приняты для расчетной
проверки**, а не получены из технической документации бортовых датчиков.
Модель движения, известные нагрузки, течение, ветер и входы управления
считаются точными. Смещение датчиков, запаздывания и выбросы здесь не
рассматриваются.

## Предварительный результат

| Параметр | Истинное значение | Средняя оценка при `low` | Средняя оценка при `moderate` |
|---|---:|---:|---:|
| Масса, кг | 78 | 77,828 | 73,858 |
| Продольное сопротивление, Н·с/м | 27 | 27,024 | 27,578 |
| Момент инерции, кг·м² | 34 | 33,977 | 33,661 |
| Сопротивление рысканию, Н·м·с/рад | 23 | 23,007 | 23,108 |

В данном фиксированном опыте при `moderate` средняя оценка массы ниже
заданного значения примерно на **5,31%**, хотя все 60 оценок прошли
проверку физической допустимости. Это проявление систематической ошибки
оценивания при шуме регрессоров и разностях измеренных скоростей.
Ошибка не устраняется простым увеличением числа вычислительных повторов.

Помимо средних оценок сохраняются эмпирические процентили 5% и 95%,
относительное смещение и число отбракованных реализаций. Процентили
характеризуют разброс **при точно заданной условной модели шума** и не
представляют собой подтвержденные доверительные интервалы параметров
настоящего судна. Нахождение истинного параметра за пределами этих
процентилей возможно и не означает ошибку формата CSV.

## Воспроизведение и проверки

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
./build/boat_marine_noise --model-only-noise > marine_noise.csv
python3 tools/marine/verify_noise_csv.py marine_noise.csv
python3 tools/marine/test_verify_noise_csv.py
```

Вывод — 12 строк: 3 уровня шума × 4 коэффициента. Содержатся СКО шумов,
число запусков и отказов, истинное значение, средняя оценка, смещение,
процентили 5% и 95%. В CI результат сохраняется в
`marine-output/parameter_noise_v019.csv` вместе с прежними расчетными
CSV. CTest проверяет повторяемость для одинакового seed, контроль без
шума, ненулевой разброс оценок и недопустимые параметры эксперимента.

## Следующие задачи

1. Проверить смещение, калибровочную ошибку физической тяги,
   коррелированный шум, запаздывания и выбросы.
2. Исследовать альтернативы разностной регрессии (оценивание по полной
   траектории, фильтрация входов, регуляризация) без утечки данных между
   обучающей и проверочной записями.
3. Измерить шум реальных ИНС, лага, компаса и неопределенность физической
   тяги; выполнить повторную оценку по этим данным.
4. Только после натурной валидации формировать доверительные интервалы,
   пригодные для инженерных заключений о конкретном судне.
