# Boat v0.17 — локальная чувствительность расчетной динамики корпуса

## Постановка

Исследуется самостоятельная неидентифицированная трехстепенная модель
морского корпуса C++ (продольное и поперечное движение, рыскание).
Результаты не характеризуют точность модели BlueBoat/Gazebo и не могут
переноситься на реальный катер без определения параметров по измерениям.

Во всех опытах одинаковая программа воздействия:

1. В течение 5 с левая и правая тяга равны 35 Н и 25 Н. Разность создает
   ненулевой момент рыскания.
2. Затем тяга обоих гребных винтов принимается равной нулю на 20 с.
3. По изменению истинных расчетных координат вычисляется модуль вектора
   перемещения за эти 20 с. Это **снос после нейтральной тяги**, а не
   удержание позиции и не погрешность навигации.

Профили среды:

| Профиль | Течение N/E, м/с | Ветер N/E, м/с |
|---|---|---|
| `calm` | 0 / 0 | 0 / 0 |
| `current` | 0,45 / −0,25 | 0 / 0 |
| `wind` | 0 / 0 | −4 / 6 |

Волновое воздействие и исходные коэффициенты, не выбранные для
возмущения, одинаковы во всех опытах. Для каждого профиля поочередно
изменяются масса, линейные сопротивления продольного и поперечного
движения, сопротивление рысканию, коэффициент ветровой силы и плечо
двух гребных винтов. Остальные параметры сохраняются.

При относительном приращении `h = 0,20` чувствительность с размерностью
метров на единицу относительного изменения определяется как

`S = [d(1+h) − d(1−h)] / (2h)`,

где `d` — модуль перемещения после прекращения тяги. Знак `S` означает
направление изменения **скалярного модуля сноса** при увеличении данного
параметра в этой конкретной траектории. Он не является частной производной
полной траектории по физическому параметру и не дает оценку его истинного
значения.

## Первый детерминированный расчет

| Среда | Базовое смещение за 20 с, м |
|---|---:|
| Без течения и ветра | 3,269 |
| Течение | 12,213 |
| Ветер | 4,368 |

Получено 18 строк (3 профиля × 6 параметров); 16 значений конечной
разности превысили условный порог 0,05 м на единицу относительного
изменения. Порог выбран **только для теста наличия реакции модели**.
Эти смещения не сравниваются с ранее опубликованными опытами v0.14/v0.15:
там использовались иные программы движения, начальные состояния,
среда и навигационный контур.

## Воспроизведение

После сборки проекта:

```bash
./build/boat_marine_sensitivity --model-only-sensitivity > parameter_sensitivity.csv
python3 tools/marine/verify_sensitivity_csv.py parameter_sensitivity.csv
python3 tools/marine/test_verify_sensitivity_csv.py
ctest --test-dir build --output-on-failure
```

CSV содержит название среды и коэффициента, относительное изменение,
базовое смещение, результаты −20% и +20%, центральную конечную разность
и изменение курса базового опыта. Проверка отвергает неполные,
повторяющиеся, нечисловые либо математически несогласованные записи.
GitHub Actions сохраняет файл в архиве `boat-marine-surrogate-v010`:
историческое название артефакта сохранено для совместимости.

## Что не доказано

- Коэффициенты массы, сопротивления, ветровой силы и плеча винтов не
  идентифицированы по измерениям конкретного судна.
- Один детерминированный расчет на каждом профиле не оценивает
  разброс и неопределенность результатов на воде.
- Ветровая сила и волны упрощены, вертикальные перемещения и качка не
  входят в трехстепенную модель.
- Нет доказательства безопасного удержания точки после отказа ГНСС.
