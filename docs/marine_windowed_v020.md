# Boat v0.20 — интегральная оценка параметров корпуса при шуме измерений

## Задача

В версии v0.19 обнаружено систематическое смещение оценки параметров
трехстепенной модели при использовании разностей измеренной скорости
на каждом шаге `dt=0,02 с`. Версия v0.20 сопоставляет первоначальный
оцениватель с оценкой по **неперекрывающимся временным окнам**.

Оба способа оценивают те же четыре коэффициента: массу корпуса,
линейное продольное сопротивление, момент инерции относительно вертикальной
оси, линейное сопротивление рысканию. Все остальные коэффициенты модели,
физические силы гребных винтов, течение и ветер по-прежнему предполагаются
точно известными. Используются только синтетические данные той же модели.

## Уравнения

При обозначениях v0.18 с продольной скоростью относительно воды `u`,
поперечной скоростью `v`, угловой скоростью `r` первоначальная регрессия
использует `(u[k+1]-u[k])/dt` и `(r[k+1]-r[k])/dt`.

В новом методе `K=25` последовательных шагов (`0,5 с`) суммируются до
образования регрессионного уравнения:

`u[j]-u[i]-sum(dt*r*v) = (1/m)*sum(dt*(T-Dq*abs(u)*u+Xwind))`
`                            - (Du/m)*sum(dt*u)`,

`r[j]-r[i] = (1/Iz)*sum(dt*(M+Mwave)) - (Nr/Iz)*sum(dt*r)`.

Здесь `i` и `j=i+K` — границы окна. Это **точные дискретные тождества**
прямой расчетной модели при отсутствии шума. Поэтому новое уравнение не
вносит дополнительного аппроксимационного интегрирования для текущего
численного метода. Далее, как и ранее, решаются две линейные задачи
наименьших квадратов размерности два.

Идентификация отклоняется, если число окон менее четырех, нарушена
непрерывность соседних измерений внутри окна, неверны временные метки,
матрица регрессии вырождена либо результат физически недопустим.
Окна не перекрываются; неполный последний интервал исключается.

## Прямое сопоставление при одинаковом шуме

Используются три профиля v0.19, по 60 повторений, одинаковые начальные
числа генератора и ровно **одни и те же шумовые реализации** в каждом
сопоставлении. Ниже приведены средние оценки при умеренном условном
шуме. Истинные значения известны из расчётной модели.

| Параметр | Задано | По разностям v0.19 | По окнам v0.20 |
|---|---:|---:|---:|
| Масса, кг | 78 | 73,858 | 77,989 |
| Продольное сопротивление, Н·с/м | 27 | 27,578 | 27,000 |
| Момент инерции, кг·м² | 34 | 33,661 | 33,986 |
| Сопротивление рысканию, Н·м·с/рад | 23 | 23,108 | 22,998 |

Смещение **средней** оценки массы в этих условиях сократилось примерно
с −5,31% до −0,014%. При этом эмпирический интервал 5–95% для оценки
массы по окнам составил `[77,462; 78,593] кг`: разброс отдельных оценок
не исчез. В других программах движения, при коррелированном шуме,
смещении датчиков и изменении размера окна улучшение не гарантировано.

Нормированный определитель матрицы регрессии проверяет вырожденность,
но не представляет собой доверительную вероятность. Эмпирические
процентили от 60 повторений **не являются доверительными интервалами
параметров настоящего BlueBoat**.

## Воспроизведение

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
./build/boat_marine_windowed_comparison --model-only-compare > windowed.csv
python3 tools/marine/verify_windowed_csv.py windowed.csv
python3 tools/marine/test_verify_windowed_csv.py
```

В CI сохраняется `marine-output/parameter_windowed_v020.csv`: 12 строк
(три уровня шума × четыре параметра) с истинными значениями, двумя
средними оценками, относительными смещениями, процентилями интегрального
метода и числом принятых реализаций. CTest проверяет совпадение с
прямой моделью без шума, уменьшение смещения при фиксированном шуме,
вырожденные исходные данные и разрывы измерений. Восемь Python-тестов
проверяют структуру и внутреннюю согласованность CSV.

## Ограничения и следующий этап

- Нет измеренной модели погрешностей датчиков и гидродинамической
  идентификации BlueBoat. Обе оценки проверяются на том же расчетном
  объекте, который генерирует данные.
- Не изучены временные задержки, пропуски, коррелированный шум и
  смещение датчиков; интегрирование может накапливать такие ошибки.
- Физическая тяга каждого гребного винта все еще предполагается
  известной, а не измеренной: реальные ШИМ/обороты не подходят напрямую.
- До использования реальных журналов необходимы строгая проверка
  единиц, единой шкалы времени и непрерывности наблюдений, проверка
  идентифицируемости на независимых маневрах и оценка неопределенности.
