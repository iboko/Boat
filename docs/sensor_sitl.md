# Boat v0.7 — замкнутый контур C++ ИНС/ESKF с моделями сенсоров

## Назначение

Цель — прекратить прямую передачу точных координат физического симулятора `SIM_STATE` в `ODOMETRY`. Вместо этого SITL-истина подается **исключительно на вход генератора виртуальных измерений**. Генератор выдает (1) IMU FRD с удельной силой, скоростями вращения, остаточными смещениями и шумами, (2) периодические абсолютные координатные коррекции условной береговой РЛС, (3) периодические измерения скорости относительно дна условного доплеровского лага. Далее данные объединяет действующий 15-компонентный ESKF на C++ и **только оценка ESKF** становится MAVLink `ODOMETRY`.

**Это не физически достоверные радиолокационные кадры**. В виртуальной береговой привязке готовые координаты синтезируются из истинных координат физической модели с искусственным шумом. В виртуальном DVL измерения моделируются из скорости физической модели, а не из акустических лучей. Инициализация ориентации выполняется из SIM_STATE как условное измерение компаса, поэтому не проверяет полную автономную оценку курса. Модель не включает реальные течения, ветер, прилив, трехмерное волнение и ограничения дна/дальности РЛС.

## Датчики и шумы

| Канал | Частота / условие | Особенности |
|---|---|---|
| Инерциальный датчик | Частота входа SIM_STATE около 10 Гц, внутренний шаг ESKF не больше 25 мс | Удельная сила через конечную разность земной скорости и обратный поворот FRD; остаточные смещения акселерометра, гироскопа и детерминированный псевдошум |
| Береговая геопривязка | Приблизительно 1,43 Гц | Шум координат; отчетная горизонтальная СКО 0,65 м; короткое отсутствие сигнала на 9–13 секунде |
| Донный доплеровский лаг | Приблизительно 3,33 Гц | Скорость относительно грунта с шумом; горизонтальная СКО 0,15 м/с; потеря донного контакта на 11–13 секунде |
| GPS1/GPS2 | Отключены в ArduPilot | Навигационный ESKF не получает ГНСС |

### Оценка

Инерциальная механизация интегрирует скорость и положение с учетом тяжести, ориентация представлена кватернионом FRD→NED. Фильтр ошибок оценивает `[позиция, скорость, ориентация, смещение акселерометра, смещение гироскопа]` с матрицей ковариации 15×15. Применяются NIS-отбраковка измерений и обновление Джозефа. В случае отсутствия геопривязанного берегового измерения более 30 с или превышения предельной неопределенности внешняя одометрия не публикуется.

В текущей версии **нет** синхронизированного чтения реального IMU, задержек, измерителя курса, полноценной статистики ошибок IMU, наблюдаемости всех компонент ESKF, истинного радарного сопоставления с картой, морской модели с ветром и течением. Отдельные источники в моделировании не являются физически независимыми от SIM_STATE.

## Проверка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure

cmake -S . -B build-mavlink -DBOAT_WITH_MAVLINK=ON \
    -DBOAT_MAVLINK_INCLUDE_DIR=/path/to/mavlink/c_library_v2
cmake --build build-mavlink --parallel

BOAT_DYNAMIC_BRIDGE_BINARY="$PWD/build-mavlink/boat_sitl_sensor" \
BOAT_DYNAMIC_MODE=sensor-eskf \
RUN_DIR="$PWD/sitl-sensor-output" \
ARDUROVER_BINARY="$PWD/sitl-smoke-output/ardurover" \
bash tools/sitl/run_sitl_dynamic.sh
```

Тест в обязательном порядке проверяет наличие физической модели SITL **до любых действий с миссией**. Автоматическое выполнение `AUTO` разрешается только в таком испытательном окружении. Критерии: действительное движение виртуальной модели по `SIM_STATE`, `MISSION_ITEM_REACHED` для всех трех точек, прохождение каждой в пределах 2,5 м, состояние AUTO/ARMED, по меньшей мере 20 сопоставимых точек физики и EKF, P95 расхождения менее 5 м для этого искусственного сценария и наличие кратковременных отказов РЛС/донного лага. Все критерии и модель условны и **не являются обоснованием допуска к автономной эксплуатации судна**.

## Дальнейшая разработка

1. Реалистичные IMU по паспортным шумам, дрейфам, температуре, несинхронным меткам и разбросу ориентации; независимое оценивание курса.
2. Моделирование ориентиров береговой РЛС/лидара с неопределенной ассоциацией, а не готовых координат.
3. Лучевая модель DVL с донным и водным режимом, зависимость от глубины и потери донного отслеживания.
4. Морская гидродинамика с течением, ветром и волной. Тесты при отсутствии берега и превышении границ навигационной погрешности.
5. Только после этих стендовых тестов — подключение реальных датчиков, контроль безопасных режимов и испытания под наблюдением оператора.
